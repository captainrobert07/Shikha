05 — Method

Four things
I believe.

i.

Start with the question, not the data.

Every good dashboard begins with someone trying to make a decision. If I can't write that decision in one sentence, I'm not ready to build anything yet.

ii.

If it needs explaining, it isn't done.

A report with a footnote, a caveat, and a twenty-minute walkthrough is just an unfinished report. Clarity happens before the share button — not after.

iii.

Default to teaching.

Every shortcut I take alone is one my team can't take tomorrow. Documentation, code reviews, pair sessions — they cost time once and save it forever.

iv.

Boring is a feature.

Production data work shouldn't be exciting. Surprises mean somebody is about to have a long Monday. We save the excitement for the discovery work.
